## 前端毛玻璃优化（Apple Design skill）
- 诉求：侧边栏(#toolbar)与右上角信息面板(#editor-panel)之前只是白色背景，毛玻璃效果不可见。
- 根因：面板虽有 `backdrop-filter:blur(28px)` + `rgba(255,255,255,0.78)`，但背后地图是纯色 `#e8e8ed`，无可模糊内容，且面板近乎不透明。
- 方案（src/main/resources/web/index.html）：
  1. 新增 `--glass-*` CSS 变量（bg 0.62 / blur(30px) saturate(190%) / light edge inset）。
  2. `body::before` 加柔和彩色光晕（蓝/紫/橙/绿 radial + 浅色线性渐变 + blur(24px)），为玻璃提供可折射内容（Apple vibrancy）。
  3. `#map` 背景改为 `rgba(236,236,241,0.6)` 半透明 + `.leaflet-container` 透明，让光晕透出。
  4. #toolbar / #editor-panel / #tool-toast / .constrain-popup / .leaflet-control-zoom 统一改用玻璃材质，带亮边高光。
  5. 完善 `prefers-reduced-transparency` 回退（含 body::before 隐藏）。
- 预览：在 src/main/resources/web 起 `python3 -m http.server 8080`（后台 task 2GDYKF），浏览器开 http://127.0.0.1:8080 查看（无后端，/api 调用会静默失败，仅看 UI/玻璃效果）。
