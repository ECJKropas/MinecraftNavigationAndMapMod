# 2026-09-06

## 导航功能（Navigation）设计共识 + 落文档

通过 Grill Pro 与用户逐步敲定 Wayfarer v1 导航功能设计，并落成三份文档：

- `docs/CONTEXT.md` — 导航域术语表（Route/Edge/Classification/Start/Destination/SnapRadius/ArrivalRadius/ClassSpeed/DistanceGate/AutoReroute/HUD）。
- `docs/adr/0001-distance-gated-routing.md` — ADR：采用"距离门控的等级加权"路由（短途走小路、长途走大路），否决扁平加权与显式三段式。
- `docs/navigation-implementation-plan.md` — 实现拆解（配置/吸附/Router/NavigationSession/Web端/游戏内HUD/多版本/测试/文档）。

关键共识：路网路线规划；起点=当前位置；终点=浏览器地图点选或坐标输入(浏览器框+游戏内malilib小窗)；浏览器地图高亮+游戏内HUD(剩余距离/下路口转向箭头/当前道路/ETA)；自动重规划；单目的地；半径内吸附(≈32)；到达自动结束(≈5)；等级速度法 + 距离门控(200格)。

代码落点：新包 `com.ecjkim.wayfarer.client.road.nav`（Router / NavigationSession / NavHudRenderer / LocationSnapper）。
已实现真实 API 参考：RoadNetworkDatabase.getAllNodes/getAllSegments/getRoad(id).getClassification()；Segment.nodeIds 为折线；Road.classification 是 String(空串=未归类)；WayfarerHttpServer 用 Route 注册、/static/(.+) 托管 web/；配置走 WayfarerConfigs.Generic + WayfarerConfig 门面。
