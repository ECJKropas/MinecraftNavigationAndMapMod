# Wayfarer（越陌度阡）B站发布视频 · 制作方案

> 目标：以「B站实用模组推荐」风格，向 Minecraft 玩家介绍 Wayfarer 的路网记录 / 测绘 / 浏览器编辑能力，完成一次发布向视频。
> 本文档包含：标题与封面建议、分镜视频稿、素材准备清单、发布前检查清单。

---

## 一、视频基本信息（先定调）

### 建议标题（备选，挑一个最贴的用）

1. **《在 MC 里迷路？这个模组把你的路网画成地图》**（痛点 + 悬念，推荐）
2. **《越陌度阡：一键把走过的小路，变成一张完整路网地图》**
3. **《MC 路网测绘神器！自动记录 + 浏览器编辑，生存党狂喜》**
4. **《这个 Fabric 模组，让我在游戏里做出了自己的"高德地图"》**
5. **《不用求服主！纯客户端模组，把任何服务器的路都画成地图》**（主打服务器/Realms 玩家，推荐备选）

> 标题公式参考：`痛点/反差 + 模组名 + 收益/悬念`。避免纯功能罗列，前 2 秒要让人想点进来。

### 封面设计建议

- **大字主标题**（占画面 1/3，加粗描边）：如「路网测绘神器」或「再也不迷路」
- **副标题小字**：Wayfarer · 越陌度阡 · 纯客户端 · 任意服务器可用
- **主体图**：游戏内路网 3D 渲染截图（节点光柱 + 连线）或浏览器编辑器地图截图，二选一最吸睛
- **配色**：深色背景 + 青/金高亮（呼应节点线框配色：绿/红/青/金）
- **人物**：可选一张你站在路口的第三人称截图，增加「真人实测」感

### 标签 / 分区

- 分区：**游戏**（Minecraft）→ 模组 / 实用mod
- 标签：`Minecraft` `Fabric模组` `实用模组` `生存必备` `地图` `越陌度阡` `Wayfarer` `MC教程`
- 简介第一行加：`【1.20.1 / 26.1.1 / 26.2 通用 · 纯客户端】`

### 时长预估

- 成片 **7–9 分钟**（B站模组推荐黄金区间，太短讲不清，太长掉完播）
- 节奏：前 30 秒必须抛出钩子，每 1.5 分钟一个小高潮

### 口播风格小贴士

- 多用「你」而非「玩家」，拉近距离；多用「牛 / 爽 / 省事」这类短评，给弹幕留梗。
- 技术词（Douglas-Peucker、反射集成、乐观并发、增量同步）**只在对应段落提一句名字即可**，不要展开，B站观众要的是"能拿来干嘛"。
- 关键按键（R、Ctrl+Alt+T、N）和网址（localhost:7891）必须口播 + 字幕双保险。
- **「纯客户端 / 带进任何服务器」是核心差异化卖点，开场、安装段、结尾至少出现三次**，服务器玩家最吃这一套。
