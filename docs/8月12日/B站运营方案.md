# Wayfarer B站运营方案

> 定位：用「AI 协作的独立模组开发者」人格，把 Wayfarer 做成中文 Minecraft 模组圈一个有技术、有梗、有社区的强势 IP。

---

## 一、品牌定位与人设

**一句话定位**
中文独立模组开发者，用 AI 把"你在 MC 里走过的每一步"变成一张可编辑、可导航的路网地图。

**人设三要素（建议贯穿所有视频）**
- **技术硬核但接地气**：敢讲架构（Douglas-Peucker、图拓扑、并发控制），也敢自嘲"我像会写 Java 的样子吗"。
- **AI 协作叙事**：把 Marvis / Codex / WorkBuddy / Trae 的协作过程当成差异化卖点，而非遮掩——这正是当下独立开发最吸粉的故事线。
- **重视社区**：读评论、回应联动诉求、公开致谢灵感来源（@Kuranoka、@迈嚮遠方、@thekingofcity）。

**差异化**
同类模组内容多是"功能演示 + 下载链接"。Wayfarer 的破局点是：**开发过程本身即内容**（AI 协作 + 真实踩坑），加上**人格化互动**（读评论），形成"人—模组—社区"的三角关系。

---

## 二、目标受众

| 层级 | 人群 | 内容钩子 |
| --- | --- | --- |
| 核心 | MC 模组玩家（建筑党 / 地图党 / 技术流）、中文 Fabric 社群 | 路网可视化、浏览器编辑器、道路分级 |
| 延伸 | 独立开发者、AI 辅助编程关注者 | "一个人 + AI 做出现役模组"的故事 |
| 破圈 | Minecraft 内容创作者、MTR / Xaero 玩家 | 联动演示、生态位 |

---

## 三、内容矩阵（栏目规划）

1. **【Wayfarer】旗舰栏目（人格化）**：教程 + 读评论、开发故事、QA、版本更新解读。承担拉新 + 固粉。
2. **技术揭秘**：把代码里的"硬菜"做成可视化（轨迹简化算法、图自动拓扑、乐观并发 409）。建立"真懂行"的权威感。
3. **开发 Vlog**：AI 协作日常实录（Marvis 写前半程、Codex/WorkBuddy/Trae 哪家免费用哪家）。强化人设。
4. **生态联动**：MTR 铁路网、Xaero 叠加、内嵌 rmp（@thekingofcity）等联动演示。借被联动方的粉丝基本盘。

> 建议节奏：旗舰栏目为"主干"，技术揭秘与开发 Vlog 为"支径"，联动为"破圈事件"。

---

## 四、本期视频策略 ——【Wayfarer】教程 + 读评论

**双重目标**：拉新（教程价值）+ 固粉（读评论的人格化互动）。
**形式**：双人对谈。单人讲解易枯燥，双人能制造梗、接话、制造信息差，完播率更稳。
**钩子（前 5 秒）**：必须一句话同时承诺"教程"和"读评论"，例如——"最近 Wayfarer 火了，今天不光教你怎么玩，还要把评论区翻个底朝天。"

**结构（建议）**
```
开场钩子(10s) → 读评论[1]求教程 → 插播教程预告/分P
→ [2]创作起源 → [3]AI还是手搓(周礼体) → [4]未来规划 → [5]联动回复(周礼体)
→ 结尾CTA(三连+评论区互动)
```

**关键决策（待与 UP 主确认，见下方访谈）**
- 场景：游戏内搭建"访谈室" vs 真人出镜？
- [1] 教程是"本期内嵌一段"还是"独立分P/nested video"？
- 双人角色分工：谁是主讲的开发者，谁是捧哏/提问者？

---

## 五、发布与运营节奏

- **频率**：旗舰栏目每周 1 更；技术揭秘 / Vlog 作为穿插（双周或月度）。
- **时段**：周五晚 / 周末 20:00–22:00（学生党与模组成员活跃高峰）。
- **标题公式**：`【Wayfarer】+ 利益点 + 悬念`
  - 例：`【Wayfarer】全网读评论+保姆级教程！这个路网模组到底怎么玩`
- **封面**：双人同框 + 大字标题 + 游戏内路网可视化（光柱 / 节点线框）作背景，信息密度高但主体清晰。
- **评论区运营**：置顶"你最想让 Wayfarer 联动哪个模组？"引导 UGC，并把高赞诉求在下一期读评论中回应，形成正循环。

---

## 六、增长策略

- **标签**：`#Minecraft模组` `#Fabric` `#独立开发` `#AI辅助编程` `#我的世界`。
- **跨平台切片**：把教程段落切 60s 短视频发抖音 / 小红书，标题走"MC 里也能有导航地图了？"。
- **借势被提及 UP 主**：视频中明确 @Kuranoka、@迈嚮遠方、@thekingofcity，并在动态/评论区主动互动，争取被反链。
- **系列化钩子**：每期结尾埋"下期预告"，把观众锁进订阅关系而非单条视频。

## 七、KPI（分层）

| 周期 | 指标 | 参考目标 |
| --- | --- | --- |
| 短期 | 完播率、评论数 | 完播 > 40%；读评论天然拉高评论 |
| 中期 | 单期涨粉、专栏订阅 | 旗舰栏目稳定涨粉曲线 |
| 长期 | 模组下载量、GitHub Star、社区投稿 | 形成"玩家自发路网作品"生态 |

---

## 八、风险与备注

- **版本敏感**：26.x 需 Java 25，1.20.1 需 Java 17，教程里务必标注，避免新手劝退。
- **致谢合规**：灵感来源与被联动方必须明确标注，既是礼数也是避免争议。
- **内容节奏**：读评论段控制在 5 条以内，过长会稀释教程价值；核心是"用评论引出信息"，不是"读评论秀"。
