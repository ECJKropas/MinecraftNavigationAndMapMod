### [6] 完整教程演示（全量内嵌 · 金浪实操）

> 金浪切第一人称，边操作边讲；柠檬酸可在旁观补一句吐槽/追问。

**① 安装**（字幕必上）
> Fabric Loader ≥ 0.19.2 + **malilib** + Wayfarer JAR，扔进 `.minecraft/mods/`。启动游戏。
> ⚠️ 提示：26.x 版本需 Java 25，1.20.1 需 Java 17——字幕标注，避免新手劝退。

**② 自动记录（30 秒爽点）**
> 按 `R` → 沿路走 → 再按 `R` → 填名称、选分级（G 国道等）、写编号 → 保存。 roads.json 自动写入当前世界。

**③ Survey 精确测绘**
> 手持任意物品按 `Ctrl+Alt+T` 设为 Survey 工具（默认小麦种子）；左键放起点、右键放中间点、左键终点/已有节点结束。

**④ 浏览器编辑器**
> 游戏运行时打开 `http://localhost:7891/`——拖拽节点、合并路段、软删交叉口，与游戏实时双向同步。

**⑤ 道路分级 + Xaero 叠加**
> G/S/Y/X/C 分级，地图按等级着色；检测到 Xaero's World Map 自动叠加路网图层。
