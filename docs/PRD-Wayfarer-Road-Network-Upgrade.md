## 3. 背景与目标

### 业务背景

Wayfarer（越陌度阡）是一款 Minecraft Fabric 客户端模组，帮助玩家记录和浏览走过的道路。当前 v0.1.x 版本已实现轨迹录制、交叉口识别和简单的浏览器地图预览，但路网展示质量远低于用户预期——纯 Canvas 手绘、无缩放平移、无底图参照、无道路分级渲染。

用户来自 Minecraft 交通建设社区，习惯使用专业 GIS 工具（QGIS 等）查看路网，对可视化质量有较高要求。

### 产品目标（SMART）

| 目标 | 指标 |
|------|------|
| 浏览器端路网展示达到专业地图质量 | 支持缩放/平移/点选，五级道路分级着色 + 沿路标签 |
| 游戏内 Xaero 地图叠加路网 | 在 Xaero 世界地图上直接显示已录制道路（P2 交付） |
| 可扩展图层架构 | 支持未来添加行政区域、兴趣点等任意图层 |
| 三版本同步支持 | P1 浏览器端同步支持 1.20.1 / 26.1.1 / 26.2；P2 游戏内叠加随 Mixin 开发进度逐版本适配 |

### 用户画像

| 角色 | 核心诉求 | 痛点 |
|------|---------|------|
| MC 交通建设玩家 | 在游戏中查看自己修建/探索的路网全貌 | 现有地图预览只有白底线条，毫无空间感 |
| 路网规划者 | 在浏览器中分析道路拓扑、规划新路线 | 无法缩放和平移，无法导出到 GIS 工具 |
| 服务器管理者 | 向其他玩家展示服务器路网 | 需要专业的地图可视化效果 |

## 4. 范围定义

### 4.1 包含范围（In Scope）

- Leaflet Web 前端重构（GeoJSON 路网图层 + 分级着色 + 沿路标签 + 图层控制）
- 可扩展图层系统（LayerManager + MapLayer 接口）
- Xaero 世界地图 Mixin 注入路网叠加（游戏内）
- 交叉口标记与道路点选交互
- 深色网格底图（浏览器端）

### 4.2 不包含范围（Out of Scope）

- QGIS 直接集成（不内嵌 QGIS 引擎，但 GeoJSON 导出可被 QGIS 消费）
- Xaero 小地图路网叠加（仅世界地图大地图）
- MC 种子地形离线渲染（P3 可选）
- 导航功能（路径规划/最短路径）
- 多人协作/服务端同步

### 4.3 MVP 边界

| 优先级 | 内容 |
|--------|------|
| **Must（P1）** | Leaflet Web 前端 + GeoJSON + 分级配色 + 图层控制 + 深色网格底图 |
| **Should（P2）** | Xaero Mixin 游戏内路网叠加 |
| **Could（P3）** | MC 地形底图（Xaero 缓存复用 / 种子渲染） |

## 7. 详细功能说明

### 7.1 图层系统

**功能描述**：管理所有地图图层的注册、可见性、层叠顺序。

**前置条件**：Wayfarer 模组已加载。

**主流程**：
1. 模组初始化时，内置图层（xaero_base、road_network）自动注册到 LayerManager
2. 用户在地图界面打开图层面板
3. 勾选/取消图层 → LayerManager.setVisible(id, bool) → 渲染端实时响应
4. 第三方模组可通过 MapLayer 接口注册新图层

**图层顺序规则**：Z-Index 从小到大绘制，底图 0、路网 100、行政区域 200、POI 300。

### 7.2 Leaflet Web 前端（P1）

**功能描述**：替换现有 Canvas 页面为 Leaflet 地图引擎。

**主流程**：
1. 浏览器访问 `localhost:7891` → 返回 Leaflet 静态页面
2. JS 请求 `/api/roads/geojson` → 获取 GeoJSON FeatureCollection
3. 按 `classification` 分组 → 每组创建独立 `L.geoJSON` 图层
4. 应用分级样式（颜色、线宽、虚线模式）
5. leaflet-textpath 插件在路段中点渲染沿路标签
6. 图层控制面板通过 LayerManager 状态同步

**异常流程**：
- `/api/roads/geojson` 返回空 → 地图显示"暂无道路数据"
- GeoJSON 解析失败 → 控制台报错，地图不崩溃

### 7.3 Xaero Mixin 游戏内（P2）

**功能描述**：在 Xaero 世界地图渲染管线中注入路网绘制。

**主流程**：
1. 用户打开 Xaero 世界地图（默认 M 键）
2. Mixin 注入 `render()` 方法，在 Xaero 地形绘制完成后执行
3. 从 LayerManager 获取 road_network 图层数据
4. 坐标投影：MC 世界坐标 → Xaero 屏幕坐标
5. 视口裁剪 + LOD 简化
6. OpenGL 绘制道路线段（分段、按等级着色）
7. 标签渲染（可选，MC TextRenderer）

**异常流程**：
- Xaero 未安装 → 路网不显示，不崩溃
- Xaero 版本不兼容 → 日志警告，Mixin 静默跳过

## 8. 非功能需求

### 8.1 性能指标

| 指标 | 目标值 | 基准测试环境 |
|------|--------|-------------|
| Web 页面加载 | ≤ 2s | CPU: i7-10700K, RAM: 16GB, GPU: RTX 2060；数据集: 500 条道路，平均长度 2000 格，视口内约 200 条可见；测量方式: Chrome DevTools Lighthouse Performance 评分 + DOMContentLoaded 事件时间 |
| 游戏内帧率影响 | ≤ 5% FPS 下降 | 同上硬件；视口内 200 条道路可见；测量方式: F3 调试屏帧率，对比启用/禁用叠加前后 30s 均值 |
| 数据规模衰减 | 2000 条道路 ≤ 5s | 同上硬件；视口内约 500 条可见；允许启用 LOD 简化 |

### 8.2 兼容与可靠

| 维度 | 要求 |
|------|------|
| 版本兼容 | P1 浏览器端三版本同步（1.20.1 / 26.1.1 / 26.2）；P2 游戏内叠加随 Mixin 开发进度逐版本适配 |
| 数据兼容 | 向后兼容旧 roads.json（新字段 optional）；缺失 classification 字段的旧道路默认按 C 村道渲染 |
| 可靠性 | GeoJSON 端点 99% 可用（本地服务）；Mixin 注入失败不影响 Xaero 正常使用 |
| 安全 | 本地 HTTP 服务仅监听 localhost，不暴露外网 |

| 风险 | 概率 | 影响 | 缓解措施 | 补充措施（V1.1.0） |
|------|------|------|----------|-------------------|

## 11. 附录

### 11.1 RoadPath.style 字段说明

`RoadPath.style` 为可覆盖配色配置，允许单条道路自定义样式（区别于 `classification` 默认映射色）。

| 场景 | 行为 |
|------|------|
| `style` 字段存在且有效 | 使用 `style` 中定义的颜色和线宽，覆盖 classification 默认配色 |
| `style` 字段不存在 | 回退到 classification 对应的默认配色方案 |
| 未来迭代 | 若需支持用户手动指定某条道路样式（如高亮），可直接修改 style 字段 |

默认配色由配置文件 `wayfarer.json` 中的 `road_styles` 字典集中管理，不硬编码在代码中。

### 11.2 调试日志

客户端模组无服务端埋点，但增加调试日志开关便于问题排查：

- 日志文件：`logs/wayfarer.log`
- 开关：`wayfarer.json` → `debug.enabled=true`
- 记录内容：图层注册/注销、GeoJSON 生成耗时、Mixin 注入状态、Xaero 版本检测结果、渲染帧耗时、异常堆栈
- 用户可通过 `/wayfarer dump-log` 命令导出日志用于问题反馈
