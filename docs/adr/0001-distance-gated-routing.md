# 距离门控的等级加权路由

为在 Wayfarer 已记录路网上实现"现实导航式"路线规划，采用**距离门控的等级加权**代价模型：每段（Edge）代价 = 段长度 ÷ 等级速度；当起终点直线距离 < `navDistanceGate`(200 格) 时弱化等级偏好（接近纯距离、走小路），≥ 阈值时启用强等级偏好（长途优先 G/S 大路）。阈值与各级速度均可在配置中调整。

## Status

Accepted

## Considered Options

- **距离门控加权（采纳）**：单趟 Dijkstra/A*，代价函数按行程距离在"纯距离"与"强等级"之间插值。实现轻、贴合"近处走小路、远处走大路"的直觉。
- **扁平等级速度**：全局统一按等级速度加权，不分远近。实现最简单，但短途也会绕去大路，不符合"近处不绕"的直觉。
- **显式三段式**：算法上把路线拆为 起点→大路入口（可走小路）/ 纯大路段 / 大路→终点（可走小路）三段。最贴近现实，但算法与边界（入口选取、断头路）复杂，v1 不必要。

## Consequences

- 短途不绕远上大路、长途优先动脉道路；实现只需在既有 Router 上加入门控代价，无需多趟搜索。
- 需为 `navDistanceGate` 与 `navSpeedG/S/Y/X/C` 提供 malilib 配置项与合理默认值（默认速度档：G5.5 / S5.0 / Y4.5 / X4.0 / C3.5 格/秒，基准步行≈4.3）。
- 未归类（classification 为空）的路段按默认/本地速度处理，避免无代价。
- 若未来需要严格的 first/last-mile 三段式，可在本模型上扩展，而非推倒重来。
