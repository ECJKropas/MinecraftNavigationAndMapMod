# Wayfarer v0.3.1 Release Notes

## 概述

v0.3.1 为小版本补丁，聚焦于地图渲染质量修复、Web 编辑器 UI 改进、自动吸附工具功能和崩溃修复。

## 新特性

- **自动取整 (autoIntegral)**：新增配置项，自动将道路节点坐标吸附到整数位，减少浮点累积误差。
- **两段式自动吸附 (autoSnapEndpoints)**：新增配置项，端点吸附现在分为两段式处理，支持更精确的端点对齐。

## 改进

- **Web 编辑器工具栏重构**：工具栏从左上角浮动卡片改为全高左侧侧边栏，避免遮挡 Leaflet 地图缩放控件。工具栏支持 compact/detailed 双模式切换，新增移动工具和描点工具。地图区域自动适配侧边栏宽度，切换时调用 `map.invalidateSize()` 重新定位。
- **Web 地图视觉增强**：道路线宽和节点半径放大 4 倍；初始缩放级别从 3 提升至 5；最大缩放级别从 8 提升至 10。

## 修复

- **路段移动崩溃修复**：修复将路段拖到 Unfiled 时因 `List.of()` 不可变列表引发的 `UnsupportedOperationException` 崩溃。`RoadMetadataScreen` 和 `RoadListScreen` 中所有对 `segmentIds` 的 `remove()/add()` 操作全部改用 `new ArrayList<>()` 可变副本。
- **Xaero 地图粗线渲染**：1.20.1 overlay 改用填充矩形 (`TRIANGLES`) 画粗线，绕过 macOS `glLineWidth` 1px 钳制上限。基础线宽调整为 4px（26.2: 4/6/8，1.20.1: 3/4.5/6），1.20.1 路线宽随地图缩放动态缩放。
- **HTTP 服务器补全**：补充 26.2 和 26.1.1 overlay 中缺失的 HTTP 服务器启动/关闭逻辑。

## 多版本兼容

- 所有修复均覆盖 base 与各 overlay 版本（26.2、26.1.1、1.20.1）。
- Web 资源文件由 base 统一构建生成，overlay 自动继承。
