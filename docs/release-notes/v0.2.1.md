# Wayfarer v0.2.1 Release Notes

**81 commits · 31 files · +1,564 / −1,896 lines**

---

## 破坏性变更

### 移除浏览器地形瓦片预览 (723e010)

彻底移除了浏览器端的地形瓦片预览功能，仅保留道路路网预览。受影响模块包括：

- 删除 `MapProvider` / `ProviderManager`（含 AUTO/XAERO_ONLY/SELF_BUILT 模式切换）
- 删除 `SelfBuiltProvider`（自建区块地形瓦片渲染）
- 删除 `XaeroProvider`（Xaero 地图缓存读取）
- `RoadPreviewServer` 移除 5 个瓦片 API 端点及 HTML 前端瓦片层/区块网格/轮询代码
- 前端移除 `maxNativeZoom` hack、多级 zoom 渲染、磁盘缓存等逻辑

保留功能：道路数据存储 (`RoadDataStore`)、道路录制 (`RoadRecordingManager`)、道路 API、Leaflet 路网 SPA、`XaeroMapOverlay` 均不受影响。

共净删除约 1,587 行代码。

## 新特性

### malilib 设置界面重写 (96d8b12)

使用 malilib 框架完全重写了模组配置界面，替代原有的自定义设置面板。按 `C` 键打开 malilib 配置 GUI，Wayfarer 分类下可配置所有选项。

### Xaero World Map 游戏内叠加层 (49475c4)

新增 `XaeroMapOverlay`，在游戏内实时渲染道路轨迹到 Xaero 小地图/大地图之上，无需打开浏览器即可查看已录制的路线。
