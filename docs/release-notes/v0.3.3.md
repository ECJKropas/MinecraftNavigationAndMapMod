## v0.3.3 + v0.3.2

> v0.3.2 was not publicly released; this release combines v0.3.2 and v0.3.3.

### New Features (v0.3.2)

- **Auto-graphify** — road network automatically enforces graph topology
- **Split/Merge tool (Fenhe)** — toolbar-based road split and merge, replaces old panel button
- **Soft delete** — smart degree-based node removal preserving road continuity
- **Smart merge** — auto-detect adjacent/skip nodes on same segment when merging
- **Web Editor: undo/redo** — full undo/redo support for road editing
- **Web Editor: road rendering rewrite** — color-coded road levels, road name labels, delete color picker
- **Web Editor: configurable max zoom** — web map zoom limits exposed as config
- **Web Editor: extension constraint toggle** — right-click move tool now shows constraint toggle
- **Web Editor: more tools** — additional editing tools added
- **Point tool: line intersection** — insert nodes at exact intersection of two line segments
- **Auto-delete orphan nodes** — config toggle to clean up orphaned nodes

### Improvements (v0.3.2)

- Removed Geoman dependency — replaced with native SVG drag + direction constraints
- Segment click radius expanded to 8px in web editor
- RoadListScreen now shows UUID last four digits

### Fixes (v0.3.2)

- Fix classification normalization for legacy multi-char values
- Fix web delta API treating roads array as object
- Fix road rendering ghosting and delta polling performance
- Fix NaN LatLng from invalid node coordinates
- Fix Xaero overlay shaking on 1.20.1 by using identity matrix
- Fix web move/point tool UI
- Fix RoadListScreen UUID display

### Fixes (v0.3.3)

- Fix malilib 0.16.3 crash on 1.20.1 — remove broken MixinGuiTextFieldGeneric
- Add `remap=false` to `@Inject` to prevent Loom from remapping malilib method names
- Add `refmap` to `mixins.json` to fix Mixin crash
- Fix softDeleteCenter NPE on merged segment in toGeoJSON
- Fix softDelete center node handling at segment endpoints
- Fix RoadListScreen scroll offset causing misclicks and search clear not resetting selection
