## v0.4.0

### Features

- **Survey Mode**: Core survey system with tool configuration, state machine, Ctrl+scroll mode switching, and input handling
- **Survey Rendering**: Node indicator renderer with particle path visualization and recording HUD
- **Survey HUD**: Mode indicators, shortcut hints, and world-space node outline + path edge rendering
- **Survey Hotkeys**: Dedicated survey hotkeys with programmatic control and block interaction cancellation
- **Xaero Map Integration**: Render unfiled survey segments on Xaero's world map overlay
- **Segment Snapping**: Snap segments to starting point in survey mode for routing accuracy
- **ToolItemManager**: Change listener support for dynamic tool item detection
- **UI/UX**: General UI and UX improvements

### Fixes

- Fix BlockInteractionMixin `startDestroyBlock` not using `CallbackInfoReturnable`, causing game crash on block interaction
- Fix `ToolItemManager.reload()` never called during init, causing held tool item to not be recognized
- Fix Y coordinate in auto recording mode using wrong value
- Fix classification i18n keys to match YAML structure
- Fix server storage path and relocate road data to game run directory
- Fix per-world/server data isolation with `worldKey`
- Fix node rendering: use `BlockRenderDispatcher` with camera transform instead of `DebugRenderer`
- Fix render buffer missing `endBatch()` call causing invisible block geometry
- Fix survey left-click not starting recording and node indicator rendering
- Fix survey data integrity and state machine edge cases
- Fix survey node creation at block click position, simplify hotkey system
- Fix HTTP `createRequest` silently swallowing request body read errors
- Fix `parseToolItem` exceptions silently swallowed, now logged
- Fix `saveRoad` transaction safety and callback cleanup
- Fix survey critical path thread safety with `synchronized` and HTTP mutual exclusion
- Fix `finishRecording` transaction protection and `saveToDisk` return value
- Fix Undo/Redo incremental merge, Config cache invalidation, asyncSave race conditions, HTTP input validation
- Fix atomic version checks, delta sync logic, and Y coordinate interpolation
- Fix `graphify` auto-split segments at shared internal nodes
- Fix config default classification dropdown and assignment logic
