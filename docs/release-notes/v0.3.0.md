# Wayfarer v0.3.0 Release Notes

## 概述

v0.3.0 聚焦于 UI 交互改进、代码架构精简和多版本兼容性修复。主要内容包括拖拽重写、Unfiled Segments 常驻、RDP 参数数值化、宽度字段移除等。

## 新特性

- **路段拖拽重写**：点击路段后文字副本跟随鼠标，拖至左栏道路条目上松开即可移动。按住鼠标时才跟随，松开即释放。支持 GLFW 实时轮询检测鼠标状态，26.1.1 版本不启用此功能。
- **Unfiled Segments 常驻**：左栏顶部"未归属路段"条目始终可见，即使无未归属路段也显示计数 `0`。

## 改进

- **RDP 参数数值化**：`RoadSimplifier.simplify()` 不再解析字符串公式，直接接收 `epsilon` 数值参数。默认值向配置暴露。
- **i18n 完善**：首页按钮改为国际化文本；拖拽标签显示翻译文本而非 i18n 键名；新增 `wayfarer.road.gui.segment` 键（en: "Segment", zh: "路段"）。
- **RoadMetadataScreen 布局对齐**：名称框与分隔线间距修正；Cancel 按钮退出时清理 DB 中孤儿数据。
- **数据库操作精细化**：`RoadNetworkDatabase` 的 `update*()` 方法改为字段级合并，`removeRoad` 级联清理关联 segment 的 `roadId`。

## 移除

- **Road.width 字段**：删除路宽度属性及相关配置体系（`WayfarerConfig` / `WayfarerConfigs` 中全部宽度相关代码）。
- **RoadSimplifier 公式解析器**：不再支持字符串公式输入。
- **旧 dragMode 字段**：替换为新的拖拽状态机（`dragging` / `draggingSegment` / `draggingLabel`）。

## 修复

- 修复 26.1.1 版本 `Screen.hasShiftDown()` 不存在导致的编译错误。
- 修复 `XaeroMapOverlay` 的 `classificationColor` 未与 `RoadListScreen` 颜色集同步的问题。
- 修复拖拽标签显示 i18n 键名而非翻译文本的问题。

## 多版本兼容

- 拖拽功能在 26.1.1 中禁用（GLFW 兼容性问题）。
- 26.2 overlay 与 base 同步所有 UI 变更。
