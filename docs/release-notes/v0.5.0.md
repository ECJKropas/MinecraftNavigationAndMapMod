## v0.5.0

### Features

- **Turn-by-turn Navigation**: Route guidance with next-turn detection, remaining distance/ETA, off-route rerouting, and a dedicated navigation HUD
- **Minimap Route Rendering**: Navigation route is drawn on the minimap, with heading indicator and navigation/edit mode gate plus tap-to-navigate on the web map
- **Xaero World Map Integration**: Navigation layers, Xaero export base map, and coordinate grid
- **Road Editing**: Merge-nearby-nodes endpoint and segment-projection snap fallback for more forgiving node/segment placement
- **Destination Bearing on Arrival**: The nav HUD and web panel now tell you whether the destination is ahead, behind, to the left, or to the right
- **Color Picker**: Classification colors migrated to malilib `ConfigColor` with an in-game color picker

### Fixes

- Fix survey mouse input not processed in `IDLE`, so survey recording could not start
- Fix missing block interaction guard on 26.x during survey
- Fix web editor undo/redo not restoring snapshots
- Fix segment view culling and remove the snap grid overlay
- Fix scroll callback registration by moving it to `CLIENT_STARTED`
- Fix coordinate grid labels to stay pinned to the map edge instead of following the viewport
- Round remaining distance to whole blocks in the navigation HUD
- Fix hard-coded Chinese UI strings by moving them into the language files

### Chores

- Bump fabric-api and Xaero's World Map to their latest releases
