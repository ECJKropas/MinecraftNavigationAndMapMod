# Wayfarer v0.2.2

> 发布日期：2026-07-22

## 新增

### 道路轨迹简化算法

录制道路时自动对原始轨迹点做两阶段后处理，大幅减少存储点数并消除采集中的冗余路径。

- **回退路径剪枝**：去除物理采集中"走了又回头"产生的 Z 字形冗余。当新采集点回访到历史旧点附近时，自动裁剪中间折返段。
- **Douglas-Peucker 曲线简化**：在保持道路几何形状的前提下，用最少的关键点表示道路折线。

### 新增配置项

- **RDP 简化容差公式**（`rdpEpsilonFormula`）：支持含占位符的公式字符串，在简化时动态计算当前道路的 epsilon。
  - 默认公式：`[RW]/2`（道路实际宽度的一半）
  - 可用占位符：`[RW]` = 道路实际宽度，`[DW]` = 等级默认宽度
  - 支持 `+` `-` `*` `/` 和括号，如 `[RW]*2`、`([RW]+[DW])/3`
  - 表达式解析失败时安全回退到 `RW/2`

## 技术细节

- 简化在录制保存和追加保存时自动执行，不影响已存储的道路数据
- 简化在端点吸附（snapEndpoints）和交叉口检测之前执行，确保几何精度
- 仅操作 XZ 平面（水平面），保留原始高度（Y）和 tick 信息
- 三版本（1.20.1 / 26.1.1 / 26.2）同步支持
