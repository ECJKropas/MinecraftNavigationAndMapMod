# Wayfarer v0.3.2 Release Notes

## 概述

v0.3.2 聚焦于道路编辑器工具的全面升级：新增软删除、分合（拆分/合并）工具，增强合并节点的同路段特判，移除 Geoman 依赖改用手动 SVG 拖拽，引入 undo/redo 支持，并增加自动图化功能确保路网结构满足图论要求。同时带来道路渲染重写、可配置缩放等级、孤立节点自动清理等多项改进与修复。

## 新特性

### 编辑器工具

- **软删除工具**：按节点度数智能删除，保留路段连续性。端点（degree=1）缩短路段移除端点；偶数度中心节点贪心配对最接近 180° 的对向路段并合并（同道路或 Unfiled 才可配对）；奇数度非端点拒绝并提示原因。
- **分合工具**：替代右上角「在此拆分」按钮。点击路段中间节点 → 拆分为两段继承道路；点击 degree=2 同名道路（或 Unfiled）端点 → 合并两路段。后端新增 `POST /api/nodes/merge-segments` 端点。
- **合并节点特判**：区分相邻节点与间隔节点场景。相邻节点：2 节点路段先删再合，多节点路段直接合并；间隔节点：检查中间节点度数，全部为 2 时弹出确认框删除中间节点后合并。
- **右键延长约束**：右键移动工具可弹出约束切换按钮，开启后拖动节点时沿道路方向投影。
- **描点工具交点插入**：支持两线段数学交点处插入共享节点，自动拆分两条路段。

### 自动图化 (autoGraphify)

- 新增配置项（默认开启），自动将道路网转化为信息学意义上的图。扫描所有度数 > 2 且仍是路段内部节点的节点，将其所在路段拆分，确保所有度数 > 2 的节点均为端点——为将来的 Dijkstra / A* 寻路提供干净的图结构。
- 在每次存盘和加载存档时自动执行，设有递归守卫防止拆分操作触发无限循环。

### undo/redo 支持

- 全量状态快照 undo/redo（Ctrl+Z / Ctrl+Shift+Z），最大 50 层。工具栏设有动态透明度按钮，连续相同快照自动去重。覆盖全部 10 个编辑操作。

### 道路渲染重写

- G/S 国道/省道按等级配色渲染，带路名牌显示。其他道路灰色细边白色填充。路名置于道路中间非交叉点。
- 删除编辑器中的颜色选择器，新增等级 (select) 和编号字段。

### 其他

- **自动删除孤立节点**：新增配置项（默认开启），每次操作后自动清理无路段连接的节点。
- **网页端最大缩放等级可配置化**：新增 `webMaxZoom` 配置（默认 10，范围 10-20），后端通过 `GET /api/config` 向前端暴露。

## 改进

- **移除 Geoman 依赖**：改用手动 SVG 拖拽（`circleMarker._path` 上绑定 `mousedown` + document 级 `mousemove/mouseup`），实现沿道路方向轴投影约束，隔离节点自由拖动，拖动中实时更新多段线。移动和合并工具下禁用地图拖拽避免冲突。
- **路段点击判定扩展至 8px**，提升操作精度。
- **RoadListScreen** 显示 UUID 后四位替代序号，便于调试定位。
- **道路分类归一化**：前端取首字母归一化旧数据中 `G国道`/`C村道` 等多字符值，后端写回时同步归一化防止未来再生多字符数据。

## 修复

- **道路渲染重影**：非 G/S 道路的 fill 多段线未被追踪，`renderAll` 清理时只清除 edge 层，现通过 `segmentFills` Map 统一管理。
- **delta 轮询性能**：每 2 秒无条件全量重建 → 改为按对象数量变化判断是否需要重绘。
- **delta roads 数组遍历错误**：`Object.entries()` 按整数下标覆盖 `roadStore`，导致所有 road 映射丢失 → 修复遍历方式。
- **NaN LatLng 防御**：`buildPoints` 过滤坐标非数字的节点，标签中点计算跳过 NaN。
- **1.20.1 Xaero overlay 抖动**：PoseStack 残留平移变换导致道路图层随视角晃动 → 改用单位矩阵。
- **Web 移动/描点工具地图拖拽冲突**：激活后禁用地图拖拽。

## 多版本兼容

- 所有特性均覆盖 base 与各 overlay 版本（26.2、26.1.1、1.20.1）。
- Web 资源文件由 base 统一构建生成，overlay 自动继承。
