## Sprint 3（第3周）：Auto 模式 + 高级编辑

### 3.1 Douglas-Peucker 轨迹压缩（Day 1-2）

#### 3.1.1 算法实现

```java
// moe.magix.wayfarer.road.analyzer.DouglasPeucker
public class DouglasPeucker {
    // epsilon 默认 2.0（MC 道路标准）
    public static List<Vec3d> simplify(List<Vec3d> points, double epsilon) {
        if (points.size() <= 2) return new ArrayList<>(points);
        
        // 找到离首尾连线最远的点
        double maxDist = 0;
        int maxIndex = 0;
        Vec3d first = points.get(0);
        Vec3d last = points.get(points.size() - 1);
        
        for (int i = 1; i < points.size() - 1; i++) {
            double dist = perpendicularDistance(points.get(i), first, last);
            if (dist > maxDist) {
                maxDist = dist;
                maxIndex = i;
            }
        }
        
        if (maxDist > epsilon) {
            List<Vec3d> left = simplify(points.subList(0, maxIndex + 1), epsilon);
            List<Vec3d> right = simplify(points.subList(maxIndex, points.size()), epsilon);
            left.remove(left.size() - 1); // 去重分割点
            left.addAll(right);
            return left;
        } else {
            return Arrays.asList(first, last);
        }
    }
    
    private static double perpendicularDistance(Vec3d point, Vec3d lineStart, Vec3d lineEnd) {
        // 点到线段的垂直距离（2D，忽略Y）
        double dx = lineEnd.x - lineStart.x;
        double dz = lineEnd.z - lineStart.z;
        double lenSq = dx*dx + dz*dz;
        if (lenSq == 0) return point.distanceTo(lineStart);
        double t = ((point.x - lineStart.x)*dx + (point.z - lineStart.z)*dz) / lenSq;
        t = Math.max(0, Math.min(1, t));
        double projX = lineStart.x + t*dx;
        double projZ = lineStart.z + t*dz;
        return Math.sqrt((point.x-projX)*(point.x-projX) + (point.z-projZ)*(point.z-projZ));
    }
}
```

#### 3.1.2 Auto 模式录制流程

```
按 R 开始（mode=AUTO）
  │
  ▼
每 Tick 记录 Vec3d → List<Vec3d> rawPoints
  │
  ▼
按 R 结束
  │
  ▼
DouglasPeucker.simplify(rawPoints, 2.0) → List<Vec3d> compressed
  │
  ▼
compressed 每个点 → Node（source=AUTO, cornerType=SHARP）
  │
  ▼
所有 Node → 一条 Segment（status=DRAFT, source=AUTO）
  │
  ▼
存入 RoadNetworkDatabase
```

**说明**：Auto 模式不区分拐角类型，统一 `SHARP`（折线）。Mapper 后续在浏览器手动修改为 ROUND。

```java
// RoadNetworkDatabase
public Segment mergeSegments(List<UUID> segmentIds) {
    // 前提：所有 segmentIds 对应的路段首尾相连
    // 合并：将所有 nodeIds 拼接，中间重复的端点去重
    List<UUID> mergedNodeIds = new ArrayList<>();
    for (UUID segId : segmentIds) {
        Segment seg = segments.get(segId);
        if (mergedNodeIds.isEmpty()) {
            mergedNodeIds.addAll(seg.getNodeIds());
        } else {
            // 跳过第一个节点（与上一段尾部重复）
            List<UUID> ids = seg.getNodeIds();
            for (int i = 1; i < ids.size(); i++) {
                mergedNodeIds.add(ids.get(i));
            }
        }
    }
    Segment merged = new Segment(mergedNodeIds, Source.USER, Status.CONFIRMED);
    segments.put(merged.getId(), merged);
    // 删除旧 Segment
    for (UUID segId : segmentIds) segments.remove(segId);
    return merged;
}
```

public List<Segment> splitSegment(UUID segId, int nodeIndex) {
    Segment seg = segments.get(segId);
    List<UUID> ids = seg.getNodeIds();
    // nodeIndex 是切割点索引，该节点同时属于两端
    List<UUID> leftIds = new ArrayList<>(ids.subList(0, nodeIndex + 1));
    List<UUID> rightIds = new ArrayList<>(ids.subList(nodeIndex, ids.size()));
    
    Segment left = new Segment(leftIds, Source.USER, Status.CONFIRMED);
    Segment right = new Segment(rightIds, Source.USER, Status.CONFIRMED);
    segments.put(left.getId(), left);
    segments.put(right.getId(), right);
    segments.remove(segId);
    return Arrays.asList(left, right);
}

### A.2 PUT /api/nodes/:id

- Body: `{ "x": 105.0, "z": 198.0, "expectedVersion": 3 }`
- 处理：检查 version → 更新坐标 → version++ → 返回更新后的 Node
- 冲突返回 409: `{ "error": "Version conflict. Current: 4" }`

### A.3 PATCH /api/roads/:id

- Body: `{ "name": "中山路", "color": "#FF0000", "expectedVersion": 1 }`
- 处理：更新 name/color → version++ → 返回更新后的 Road
- 如果 roadId 不存在（新建 Road），创建新的 Road 对象

### A.4 POST /api/merge

- Body: `{ "segmentIds": ["seg_001","seg_002"], "expectedVersions": {"seg_001":5,"seg_002":3} }`
- 处理：逐个检查 version → 合并 nodeIds → 删除旧 Segment → 返回合并后的 Segment
- 任一 version 冲突返回 409
