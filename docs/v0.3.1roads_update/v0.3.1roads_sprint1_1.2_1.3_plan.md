# Sprint 1 深度重构：1.2 + 1.3 实施计划

## 当前状态

- 数据模型（Node/Segment/Road/RoadNetworkDatabase）已完成
- **无 HTTP 服务器**——需从零创建
- **无 Web 前端**——需从零创建
- WayfarerClient 没有服务器启动/关闭逻辑

## 实施步骤

### 1.2 HTTP 服务扩展

#### Step 1: 创建 WayfarerHttpServer.java
- 路径：`com.ecjkim.wayfarer.client.road.server.WayfarerHttpServer`
- 功能：
  - 路由注册架构（Map<Method, Map<Pattern, Handler>>）
  - Request/Response 封装记录
  - 静态文件服务（从 classpath `web/` 读取）
  - 所有 API 实现（附录 A 的 6 个端点）
  - 版本冲突检测（409）
  - 合并/拆分端点

#### Step 2: 修改 WayfarerClient.java
- 游戏进入世界时启动 HTTP 服务
- 游戏退出时关闭 HTTP 服务
- 在 `ClientTickEvents.END_CLIENT_TICK` 中检测世界进入

### 1.3 浏览器前端基础

#### Step 3: 创建 index.html
- 路径：`src/main/resources/web/index.html`
- 使用 Leaflet CDN
- 布局：地图（70vh）+ 侧边栏（30vh）

#### Step 4: 创建 app.js
- 路径：`src/main/resources/web/static/app.js`
- 功能：loadData / onNodeDragEnd / onSegmentClick / startPolling
- 视觉区分规则

### 修复：网页服务器

上述 Step 1+2 即修复（从无到有创建 HTTP 服务）。

## 风险点

1. Leaflet 依赖 CDN 需要网络——mod 运行时玩家通常在线，可接受
2. `updateNode` 当前只更新 cornerType——需要扩展为更新坐标
3. RoadNetworkDatabase 缺少 API 需要的 `mergeSegments`/`splitSegment` 方法——需新增
