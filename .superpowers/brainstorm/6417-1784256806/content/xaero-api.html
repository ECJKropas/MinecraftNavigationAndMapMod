Xaero 集成：技术可行性前置问题

要将 Wayfarer 路网渲染到 Xaero's World Map 上，需要回答几个关键问题

Xaero's World Map 的技术边界

集成方式 可行性 说明
Waypoint 注入 高 Xaero 支持程序化添加/读取 Waypoint；每个路网节点作为 Waypoint 注入
自定义渲染层 中 需确认 Xaero 是否暴露 Mixin 钩子或渲染事件；可能需要 Mixin 注入
线/路径绘制 API 低 Xaero 本身可能不提供"画线"API；需自行在 Xaero 渲染管线中绘制道路线段
独立 Canvas 叠加 高 在 Xaero 大地图 GUI 上层叠加自渲染 Canvas，最可控但需处理坐标同步

当前需要确认的关键问题

你是否已经调研过 Xaero's World Map 的源码或 API？具体来说：

  1. Xaero 是否暴露了渲染钩子（如 Mixin 注入点、渲染事件回调），允许第三方模组在大地图上绘制自定义内容？
  2. Xaero 的 Waypoint 系统是否支持程序化批量增删？有没有公开的 Java API？
  3. 如果不走 Xaero 内部渲染，是否接受 用独立 Mixin 在 Xaero UI 上层叠加渲染 Canvas？
