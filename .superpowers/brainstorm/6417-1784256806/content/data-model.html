设计章节 1：统一路网数据模型

当前 roads.json 只存轨迹点 + 交叉口，需升级为支持分级渲染的完整路网模型

核心数据结构

实体 字段 说明
RoadPath
道路		 id, name, number
classification (G/S/X/Y/C)
width, points[], segments[]
color_override, dash_pattern
created_at, updated_at 		单条完整道路。classification 决定默认渲染样式。
segments 按交叉口切分，每段独立渲染。
RoadSegment
路段		 id, parent_road_id
points[], length
start_intersection, end_intersection 		两个交叉口之间的子段。
支持分段样式覆盖和独立 LOD。
Intersection
交叉口		 id, position (x,y,z)
connected_segments[], type
name, label_offset 		路口节点。type 区分 T字/十字/环岛。
渲染时高亮 + 名称标注。

道路分级配色方案（MVP: A+B）

等级 标识 线宽 颜色 标签样式
国道 G G 3-4px #D9432B 红 红底白字标签，沿道路方向
省道 S S 2-3px #F0A030 橙 黄底黑字标签
县道 X X 1.5px 白底灰边 白底灰框标签
乡道 Y Y 1px #adb5bd 灰 灰字，缩放至一定级别显示
村道 C C 0.5px #dee2e6 浅灰 不显示标签（高缩放级别可见）

与现有数据模型的兼容策略

现有 roads.json 格式不变，新增字段均为 optional。旧数据加载时自动补全默认值。RoadSegment 首次基于现有 intersection 数据自动切分生成。
