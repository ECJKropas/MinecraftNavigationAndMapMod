Wayfarer 路网展示升级：三条技术路线

当前瓶颈：纯 Canvas 手绘 → 无底图 · 无缩放平移 · 无可视化图层 · 无外部工具互通

路线对比概览

维度 A · QGIS 集成 B · Xaero 联动 C · 自建轻量地图引擎
底图 OSM / 自定义瓦片 MC 世界地形（区块级） MC 种子生成瓦片
缩放/平移 原生支持（GIS 引擎） 原生支持（游戏内小地图/大地图） 需自建（Leaflet/OpenLayers）
路网渲染 GeoJSON 叠加层 Waypoint/路径注入 Xaero 完全自主可控
使用场景 浏览器 / 外部 GIS 工具 游戏内 HUD + 全屏大地图 浏览器（当前 Web 预览升级）
开发量 中高（需 GIS 知识 + 坐标映射） 中（需逆向/兼容 Xaero API） 低-中（Web 前端为主）
风险 MC→GIS 坐标映射复杂；QGIS 非游戏原生体验 依赖第三方 mod；API 可能不公开/不稳定 底图生成复杂；AI 辅助开发边界

A · QGIS 集成

路网导出为 GeoJSON，叠加在真实地理底图或 MC 世界自定义瓦片上，通过 QGIS/Leaflet 查看

┌─────────────┐
│ Wayfarer │
│ (轨迹录制) │
└──────┬──────┘
       │ 路网数据
       ▼
┌─────────────────────────┐
│ Xaero's World Map │
│ ← 注入 Waypoint/Path │
│ ← 游戏内 HUD + 大地图 │
└─────────────────────────┘

B · Xaero 联动

将 Wayfarer 路网数据注入 Xaero's World Map，在 MC 游戏内叠加显示路网

C · 自建轻量地图引擎

Web 端引入 Leaflet/MapLibre，MC 侧生成地形瓦片，路网作为独立图层叠加

推荐优先级

建议 B + C 并行：Xaero 联动覆盖游戏内体验，Leaflet Web 预览覆盖浏览器端。QGIS 作为后期高级用户选项。

关键决策点

是否接受依赖 Xaero（第三方模组）？如果不接受 → 全力投入路线 C。如果可以接受 → B 是游戏内体验最优解。
