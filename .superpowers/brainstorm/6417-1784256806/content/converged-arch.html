两个渲染端的差异与互补

Xaero 游戏内 Leaflet 浏览器
底图来源 Xaero 已渲染的 MC 地形 种子离线渲染瓦片 / 空白网格
渲染方式 OpenGL 即时模式（Mixin GL） Canvas/SVG（Leaflet 矢量图层）
交互 跟随 Xaero 地图交互 完整 Web 交互（点选/筛选/导出）
开发难度 高（Mixin + OpenGL + 逆向） 中（Web 前端，AI 友好）
风险 Xaero 更新导致 Mixin 失效 底图瓦片生成复杂度

推荐 MVP 顺序

  1. 第一期：Leaflet Web 预览升级 — 风险最低、AI 辅助开发最友好、立即解决"路网展示不尽如人意"的核心痛点。用 GeoJSON + Leaflet + 路网样式配置替代现有 Canvas 手绘。
  2. 第二期：Xaero Mixin 路网叠加 — 参考 XaeroPlus 源码，在 Xaero 大地图渲染循环中注入路网绘制。先做只读展示，后加交互。
  3. 第三期：MC 种子地形底图 — 为浏览器端生成地形瓦片，替代空白背景。可参考 Cubiomes Viewer 等开源项目。
